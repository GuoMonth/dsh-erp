# alpha.6 通用浏览器学习验收

日期：2026-09-13。定位为 Adapt ERP，npm 包名仍为 `@guosheng_047/dsh-erp`。本记录是本地源码和预编译 TGZ 验证，不以发布成功替代业务验收。

## 产品方向修正

SCM/USA 只作为历史测试对象。生产源码移除固定 API、登录令牌、菜单响应结构和 SKU/订单关联假设；旧 alpha.5 编译实现冻结在 tests/fixtures/scm-alpha5，仅供回归。通用流程从用户配置的 ERP 和空知识目录开始，通过可见 UI 发现菜单、字段、状态样本及表格数据，由 DSH 解释和关联业务知识。

新增 erp_connect、erp_browser_snapshot、erp_browser_action、erp_learning_import_snapshot 和 erp_learning_extend。保留固定系统 ID、身份范围、SQLite 版本、证据、备份和恢复。已有 alpha.5 知识可以继续查询，不会自动作为其他 ERP 的已验证方法执行。

所有交互单独确认，包括查询、筛选、滚动及可能写入的按钮；观察和普通本地知识保存不逐条确认。模型规划学习，插件不声称具备无人值守全站爬虫。短期元素引用绑定页面、revision、元素内容/值及所在行/窗口，执行前重查，派发前消费，失败不自动重试。取消无法撤回已经发出的业务请求。

## 本地验证

Linux x64、Node 24.18.0、DSH 0.1.5-rc.2、Playwright 1.63.0。执行 `npm run verify`，最终完整通过：TypeScript typecheck、73 项测试、独立 TGZ 消费者和真实 DSH CLI。

| 验证 | 证据和结果 |
| --- | --- |
| 两种不同合成 ERP | 英文导航/筛选表单与中文树状入口/窗口布局；不提供 SCM API 或专用令牌 |
| 从空知识开始 | 初始 observation 数量为 0，观察菜单并导入结构、字段与选项；由测试决策构造有证据的业务域和菜单关联 |
| 真实工具执行 | 原生 DSH tools/approval → 执行进程 IPC → Chromium → 本地 SQLite；批准点击、选择、填写、查询及打开/关闭窗口后返回新快照 |
| 写入与拒绝 | 拒绝交互时合成站点写计数保持 0；明确批准合成写入后为 1；旧引用再次执行被拒绝，计数仍为 1 |
| 目标变化 | 按钮内容变化、同一 DOM 按钮所在数据行从 Item A 变为 Item B，均拒绝旧引用；快照能发现新内容 |
| 观察排除 | 隐藏信息、凭据字段、data-erp-private 及按钮内的私有子标签不进入结果；这不是完整脱敏证明 |
| 知识和队列 | 新发现浅层任务排在待执行深层任务前；重启后知识可无浏览器读取，任务暂停并按新版本恢复；导出通过 |
| 安装产物 | 独立安装 TGZ，存储/恢复、原生模型服务和工具、浏览器生命周期通过 |
| 真实 DSH CLI | 隔离 profile、持久 patch 配置；固定测试模型从快照选择实际菜单、经审批交互、读取字段并导入本地知识；退出清理通过 |
| 发布边界 | 白名单仅运行代码和用户指南；不包含 dist/scm、测试/验收资料、用户库、证据、导出或浏览器资料；构建先清理 dist |

测试选择与预期值只存在开发测试代码中，未提供给生产运行时。旧 SCM 基准仍独立运行，不能算作新通用路径的实测效果。

## 限制和后续验收

未使用真实模型重新评测未知第三方 ERP 的整体学习效果，也未重跑真实 ERP 业务链、QR/SSO、Windows/macOS 或默认沙箱桌面验收。合成测试关闭沙箱并采用 headless，不代表用户桌面默认路径已验收。

全面学习仍由 DSH 模型逐步规划，并受每次交互确认、可见 DOM、采样上限、单页面和应用范围约束。没有全部菜单层级自动证明、隐藏状态完整性、跨域/Canvas/封闭 Shadow DOM、实体改名自动修复、完整事务、自动重试或多 ERP 路由保证。生产不能预置测试答案来替代未知系统学习。

发布使用现有手动 Trusted Publishing Action，不增加 push/PR CI。发布后应单独核对 npm/GitHub 字节及精确版本安装；源码验收不提前声称 registry 发布成功。
