# Adapt ERP：通用浏览器学习

适用版本：0.1.0-alpha.6。产品面向用户配置的 ERP，运行路径不依赖厂商接口或预装站点知识。SCM/USA 是历史验证对象，其固定适配代码仅保留在 `tests/fixtures/scm-alpha5/`，不参与默认运行或 npm 发布。

## 首次全面学习与持续使用

`配置 → 人工登录 → 确认身份 → 页面快照 → 全局菜单框架 → 功能页面 → 字段/Tab/窗口 → 业务解释与关联 → 使用时复核和增量学习`。

DSH 模型承担规划、理解和下一步决策。插件提供观察、受确认的交互、持久化队列、证据、知识修订与查询。用户可以用“开始全面学习”启动一个对话任务；这不代表插件另有一个无人值守后台爬虫。

首次按当前身份可见菜单建立整体框架，再按业务域深入。点击入口之前只记录发现，不能算访问成功；看到状态选项只能作为观察样本，不能推断全部值域或合法状态转换。菜单与业务域分开记录，通过有证据的关系关联。采购和销售如何关联商品，应从当前网站的页面、文档或用户解释学习，不能沿用测试系统中的字段名与关联公式。

普通使用也走同一循环：查已有知识 → 观察当前页面 → 用当前快照定位目标 → 请求单次交互确认 → 读取结果 → 更新知识。可把学到的方法保存为 operation/rule 节点的描述、上下文和依赖；这些描述不是可绕过授权的脚本，也不保存可跨会话使用的元素引用。

## 工具协议

| 工具 | 责任 |
| --- | --- |
| `erp_system_status` | 当前配置、固定 ID、身份范围与目录；不打开网页 |
| `erp_connect` | 打开配置入口，等待用户登录；不读取指定厂商令牌 |
| `erp_browser_resume` | 用户核对登录账号/公司/角色后，允许最多 10 分钟的可见页面观察 |
| `erp_browser_snapshot` | 保存当前可见文字/表格、字段值、选项、控件及应用内 frame；返回证据 ID 和短期元素引用 |
| `erp_learning_import_snapshot` | 从证据建立页面、菜单、控件、字段及部分结构关系；保留版本和用户修订 |
| `erp_learning_start/status/extend/finish_unit/pause` | 四级显式任务、增量发现、先广后深调度、证据/阻塞、暂停恢复 |
| `erp_browser_action` | 确认一个精确目标的 click/fill/select/scroll，随后读取并保存结果；旧引用失效 |
| `erp_knowledge_*` | AI 解释、菜单/业务关联、用户修订、查询、版本与本地导出 |

snapshot 导入器只建立可见结构，并不会自动证明菜单父子层次、跨页业务关系或某个操作的效果。DSH 应在后续观察中补充这些关系。相同观察重复导入幂等，新的观察产生修订；用户已修订或 AI 已深入解释（interpreted）的节点不被结构导入器覆盖；新证据仍可供模型复核这些解释。相同页面模板中的重复行控件可能归为同一结构项，解释时须补充对象和窗口上下文；改名/改布局后的实体匹配仍需模型复核，不能宣称已实现完整自动修复。

队列可随发现扩展：每次最多 200 个新任务，总数最多 2000。新发现的浅层任务先于待执行深层任务；已完成任务不被隐式重开。进度统计只覆盖已登记任务，不把自发现数量当作网站全部功能。进程重启后运行中任务会暂停，需读取最新版本再明确恢复；浏览器许可不会随检查点恢复。

## 精确目标与授权

每份快照的控件引用最多保留两分钟，仅用于当前页面、sessionId、revision、snapshotId。引用绑定真实元素句柄及当时的元素内容、字段值和所在行/窗口上下文；执行前重新检查。页面、目标内容、身份范围或快照改变时应重新观察，不传自由选择器、脚本或网络请求。动作发出前消费引用；失败不自动重试。

**所有交互均经过宿主单次确认，包括查询、填写筛选条件、点击菜单、可能写入的按钮及滚动。** 陌生 ERP 可能在输入或普通按钮上自动保存，不能仅凭“查询”意图或按钮文案保证无写入。拒绝/缺少审批通道不执行动作；本地观察和普通 AI 知识积累不逐条询问。审批展示配置范围、快照中的目标、操作、输入值和用途。用户应检查真实效果；模型给出的用途是解释，不是副作用证明。

审批包括读取本次结果及续开有时限的观察窗口，不授权后续动作。人工操作/导航会暂停观察。取消动作会关闭所属浏览器上下文以停止后续执行，但无法撤回已经发出的请求；超时、DOM 变化或落库失败都可能发生在动作之后，错误必须按“先检查结果”处理。原生 alert/confirm 对话框保持人工处理，不自动确认。

这个预览版牺牲部分交互便利以确保写入也经过确认。未来减少纯浏览步骤的确认，需要另行设计和验证权限边界，不能用测试 ERP 的 GET 清单或关键词规则冒充通用只读证明。

## 范围与数据

快照最多 10 个应用内 frame，每 frame 最多 30000 字符和 500 个候选控件、总体最多 300 个可用引用；达到限制会返回标记。仅采集当时可见 DOM，隐藏区域和跨应用 frame 跳过。原生 select 提供可见选项标签与当前值；自定义下拉需要用户确认打开后再次观察。字段样本不是完整枚举定义。

密码/隐藏/文件输入、明显凭据标识字段、密码表单及 data-erp-private 区域排除。文本遮盖明显令牌样式，但不是完整业务数据脱敏器。普通表格与字段可能含敏感业务信息，观察会保存在本机，并可能发送给 DSH 配置的模型供应商。跨域 iframe、Canvas、封闭 Shadow DOM、复杂 SSO/多窗口及大规模列表仍有限制。

应用 Base URL 限制插件选择的页面和元素链接，不是网络防火墙；网站自己的脚本、人工操作及 DSH 其他工具不在此工具面的保证内。无自动 SQL/API 探测、任意 evaluate、自动上传或完整业务事务工具。

## 发布与验证分离

npm 白名单仅包含编译代码、清单、许可证、更新记录和用户指南。不包含测试 fixture、验收清单/答案、数据库、证据、导出或浏览器资料。构建清理 dist，防止已删除适配器残留。用户知识不参与源码提交或发布，分享仅通过用户主动导出；导出内容不会自动授权操作。

历史 SCM 测试保留为冻结回归基准；通用路径测试使用不同布局/语言的合成 ERP，从空目录起步，通过真实 Chromium、IPC、原生 tools 与审批验证菜单发现、字段选项、业务关系记录、队列增量、拒绝动作、明确获批的合成写入、目标变化及重启复用。预期值在测试断言里，不作为生产知识分发。测试决策是确定性的，不等同于真实模型在未知 ERP 上的效果评测。

当前尚未以真实模型重新完成未知第三方 ERP 的全面探索、扫码/SSO 或跨平台桌面验收。历史 SCM 实测不能替代这项验证。发布 alpha.6 表示通用浏览器学习路径可用，不表示所有 ERP、所有业务流程或无人值守全量学习均已验收。
