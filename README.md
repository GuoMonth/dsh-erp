# dsh-erp

面向 ERP 网站的学习与辅助操作插件，目标宿主版本锁定为 **dsh 0.1.5 rc2**。

通过用户登录后的浏览器会话，逐步积累菜单地图、页面结构、字段含义、状态值、业务关系和操作经验。知识可查看、纠正并追溯证据；每次向 ERP 写入业务数据前必须获得用户对具体变更的确认。

## 当前状态

项目处于第一版方案阶段，尚未实现或验证与 dsh 的兼容性。版本目标已经确定，官方仓库、插件 SDK、权限、界面及任务恢复接口仍需核对。

## 第一版范围

- 一个 ERP、一个角色和一个业务域。
- 用户登录与人工接管，优先使用只读账号开展学习。
- 菜单地图、页面索引和带证据的字段知识文档。
- 少量可复用查询，以及知识查看、纠正与版本管理。
- 测试环境中的一个受控写入流程，验证确认、中断恢复和结果回读。

## 技术方向

薄插件＋Python 模块化 ERP 能力服务＋可替换浏览器执行器＋PostgreSQL。默认评估 browser-use；宿主已有完整代理循环时评估 browser-harness。任务恢复优先复用宿主，不足时引入 LangGraph；复杂关系检索按需求引入 Graphiti。

完整架构、组件边界、学习与审批流程、阶段和验收标准见 [第一版规划](docs/v1-plan.md)。
